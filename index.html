Dicas: Gerais

Sempre mantenha seu dispositivo atualizado

Para manter-se seguro, sempre atualize seus dispositivos.

Ative um bloqueador de anúncios

Para evitar anúncios, use um bloqueador de anúncios como uBlock Origin.

Use autenticação de 2 fatores

Para aumentar a segurança, use autenticação de 2 fatores (2FA) onde possível.

Tenha senha no seu Wi-Fi

Para evitar acessos indesejados, tenha senha no seu Wi-Fi. Evite sempre usar redes sem senha.

Segurança extra

É recomendado o uso de um serviço de VPN como Surfshark para esconder seu endereço IP e histórico de navegação de sua operadora.
